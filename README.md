# Counter-Strike 1.6 Takeover

**Quake** × Counter-Strike 1.6 · visual · idea by the team

Bring Counter-Strike 1.6 into the game in the most visible and funny way. The change shows in the first 30 seconds of play.

> Counter-Strike meets Quake: Terrorists and Counter-Terrorists brawl in a dusty haze while I snipe headshots and blow up the bomb.

## Install

Copy the mod folder next to Quake's id1 folder (for example quake/cs16) and start Ironwail with: -game cs16. Choose a map from the console, like: map start. Use the number keys to switch between AK-47, Desert Eagle, AWP, M249 and grenades.
